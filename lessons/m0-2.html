One key, many doors

Imagine one key that opens your house, your school locker and your cycle lock. You only have to keep one key safe.

A GitHub account is that key. Once you have it, the other websites in this course let you in with a Continue with GitHub button. No new passwords to remember.

You will make one more account later, in Module 7 (Groq, for free AI). That lesson walks you through it.

Make the accounts (about 20 minutes)

A. GitHub (do this first)

Already have a GitHub account? Skip to part B.

  1. Open a new browser tab: press Ctrl + T.
  2. Type github.com/signup in the address bar and press Enter.
  3. Type your email address. Click Continue.
  4. Make a password (at least 15 characters, or 8 with a number and a small letter). Click Continue.
  5. Choose a username. This becomes part of your public profile link, so choose something professional, like your name. Click Continue.
  6. Solve the small puzzle that proves you are a human.
  7. GitHub emails you a code. Open your email in a new tab (Ctrl + T), open the email from GitHub, select the code and copy it (Ctrl + C).
  8. Switch back to the GitHub tab: press Ctrl + Tab until you see it, or click the tab at the top. Click in the code box and paste (Ctrl + V).
  9. If GitHub asks questions about you, you can click Skip personalization. If it asks for a plan, choose Free.

B. Supabase

  1. New tab (Ctrl + T). Go to supabase.com.
  2. Click Start your project (or Sign in) at the top right.
  3. Click Continue with GitHub.
  4. A GitHub page asks "Authorize Supabase?". Click the green Authorize button.
  5. You land on the Supabase dashboard. Do not make a project yet. You will make one in Module 2.
On the free plan, a Supabase project that nobody uses for about a week gets paused. Nothing is lost: open the project and click Restore (or Resume) and wait a minute.

C. Upstash

  1. New tab. Go to console.upstash.com.
  2. Click Continue with GitHub (or the GitHub logo). Click Authorize if GitHub asks. Logging in with Continue with Google works just as well; just remember which one you used.
  3. If it asks questions (company, use case), fill in anything; "Learning" is fine. You land on the Upstash console. Nothing else to do today.

D. Vercel

  1. New tab. Go to vercel.com/signup.
  2. If it asks for a plan type, choose Hobby ("I'm working on personal projects"). Type your name, then click Continue.
  3. Click Continue with GitHub, then Authorize.
  4. You land on the Vercel dashboard. Done.

E. Bookmark all four dashboards

  1. On each of the four tabs, press Ctrl + D and click Done.
  2. To keep them tidy: in that same box, click the Folder dropdown, choose Choose another folder…, click New folder, name it System Design, and click Save. Put all four in it.

Let your browser save the GitHub password when it offers (a "Save password?" box appears). Click Save. Also turn on two-factor login on GitHub when it suggests it; it protects everything else.

Quick quiz

Why make GitHub first?

Because Supabase, Upstash and Vercel all let you log in with GitHub, so you have one login instead of four.

A site asks for your card number. What do you do?

Stop. Go back and pick the free plan (Free / Hobby / Starter). Nothing in this course needs payment.

Your Supabase project says "Paused". Did you lose your data?

No. Open it and click Restore / Resume. Free projects pause after about a week of no use.

What is Redis (Upstash) used for, in one line?

A very fast memory store, used for caching and counting things like requests. You will learn it properly in Module 2.
