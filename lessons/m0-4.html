The cupboard with labelled boxes

If you throw all your toys into one big bag, finding the red car takes forever. If you have a box for cars, a box for blocks and a box for books, you find the red car in two seconds.

Your notes work the same way. Today you make one folder per module, and a simple routine so the 2 hours each day go smoothly.

How to remember what you learn

Reading something once is not enough; most of it is forgotten within a few days. Three simple habits fix that:

  1. Write it in your own words. After each lesson, write three short lines (the template is below). If you cannot write it simply, you have not understood it yet; read that part again.
  2. Say it out loud. Explain the topic to an empty chair (or a friend) as if they were 10 years old. This is called the Feynman technique, and it is exactly what an interview is: explaining out loud.
  3. Come back to it. Every Sunday, answer the "Check yourself" questions of that week's lessons again, without looking. Whatever you get wrong, re-read.

The three-line note (use this for every lesson)

Topic:
1. In one line, what is it?
2. The everyday example (the story):
3. When would I use it, and what does it cost me? (the trade-off)

Line 3 is the most important. In interviews, "it depends, and here is why" beats a memorised definition every time.

Make your folders (about 15 minutes)

A. Make the main folder

  1. Open File Explorer: press ⊞ Win + E.
  2. On the left, click Documents (or a drive such as D: if you keep your work there).
  3. Right-click on an empty white area (not on a file) → New → Folder. Shortcut: Ctrl + Shift + N.
  4. A new folder appears with its name highlighted. Type System Design Notes and press Enter.
  5. Double-click the new folder to go inside it.

B. Make one folder per module

  1. Inside System Design Notes, press Ctrl + Shift + N, type the first name from the list below, and press Enter.
  2. Repeat for each name. (To copy a name: select it below, Ctrl + C, then paste it when the new folder's name is highlighted with Ctrl + V.)
M0 Get ready
M1 Internet
M2 Building blocks
M3 Big ideas
M4 Interview method
M5 Design problems
M6 LLD
M7 AI design
M8 Get the job

Starting each name with M0, M1, M2… keeps the folders in the right order automatically.

C. Make your notes file for Module 0

  1. Double-click the folder M0 Get ready.
  2. Right-click on empty space → New → Text Document. Type notes and press Enter.
  3. Double-click notes.txt. It opens in Notepad.
  4. Click Copy on the three-line note box above, click inside Notepad, and press Ctrl + V.
  5. Fill it in for today's topic: "Excalidraw". Save with Ctrl + S.
  6. Move yesterday's drawing in: go to Documents, right-click 00 client-server.excalidraw → Cut (Ctrl + X), open M0 Get ready, right-click empty space → Paste (Ctrl + V).

Want your notes on your phone too? Use Google Docs instead of Notepad: go to docs.google.com, click Blank document, and name it "System Design Notes". It saves itself and opens on any device.

D. Set up your "say it out loud" recorder

  1. Press ⊞ Win, type Sound Recorder, press Enter.
  2. Click the red record button. Explain "what is a client and what is a server" in under 1 minute, as if to a child.
  3. Click stop. Listen back. Did you say "um" a lot? Did you explain it clearly? You will do this after every lesson; by Module 4 it will feel natural.

E. Put the study time in your calendar

  1. Pick your 2 hours. The same time every day works best (for example, 7–9 pm).
  2. On your phone, open the Clock app → Alarm → +, set it 5 minutes before your study time, select every day except Sunday, and save it.

Why say topics out loud?

Because the interview is out loud. Explaining simply shows you really understand, and practising removes nervousness.
